## 이번 차수 범위

넣을 것
1. **폭탄병**(새 규칙 — GAME_DESIGN 6.3 4단계, 6.5에 이미 있던 것)
2. **캠페인 10개 층**: 1~5층은 그대로(체험 구간), 6~10층 본편 추가(GAME_DESIGN 8절)
3. **되감기**(층당 1회, GAME_DESIGN 6.6)
4. 체험 구간 끝 표시: 5층을 깬 뒤 한 번 "체험 구간 끝 — 여기부터 본편". 잠금·결제는 넣지 않는다

미룰 것
- 매 턴 자동 저장/재개, 일시정지, 층 소개 화면, 층 선택 → 4차
- 무작위 런, 유물 → 5차 (대표 결정대로 캠페인 뒤)

로드맵과 달라진 점과 이유
- 2차 때 쓴 3차 안은 "폭탄병 + 층 10~12개 + 되감기 + 저장/재개 + 층 소개 + 일시정지"였다. 한 번의 빌드에 다 넣으면 새 적과 층 5개의 검증이 묻힌다. 플레이에 바로 영향을 주는 것(폭탄병, 층, 되감기)만 남기고 나머지는 4차 "캠페인 마무리"로 묶었다.
- 층은 12개가 아니라 10개. 본편 다섯 층으로 감을 먼저 본다.

## 규칙 변경과 근거

**바꾼 규칙은 없다.** 2차의 의문("생각 없이 걸어도 깨진다")을 규칙으로 또 고치지 않고 콘텐츠로 다뤘다.

### 1. 폭탄병 (추가 — GAME_DESIGN 6.5, 6.3 4단계 그대로)
- 무엇을: 체력 1. 쿨다운 0이고 플레이어와 거리 3 이하면 플레이어의 **현재 칸**에 폭탄을 던진다(아니면 졸개처럼 이동). 폭탄은 2턴 뒤 그 칸과 상하좌우 4칸에서 터져 플레이어 피해 1, 적 피해 1(오사). 던진 뒤 쿨다운 3.
- 왜: 한 수 앞만 봐서는 피할 수 없는 첫 위협이다. 그리고 폭발이 적도 다치게 해서 "끌어들이기"가 하나 더 생긴다.
- 시뮬레이션: sim.py에 1차부터 구현되어 있었고 수치를 바꾸지 않았다. 무작위 8층 런(6층부터 폭탄병)에서 2수 앞 봇 20런 중 16런 완주.

### 2. 캠페인 층 설계 기준 (추가 — GAME_DESIGN 8절)
- 무엇을: 본편 층은 "1수 앞 봇은 피해 2 이상 또는 실패, 2수 앞 봇은 피해 0, 3수 앞 봇은 피해 0으로 30턴 안"을 만족해야 한다. 체험 층은 1수 앞 봇도 피해 0.
- 왜: 계획 이득이 줄었다는 2차의 의문에 대한 답. 규칙을 또 바꾸면 2차에서 고친 것(칼 하나)의 효과를 볼 수 없다.
- 시뮬레이션(전 → 후)

| 확인 | 2차의 다섯 층 | 3차 본편 다섯 층 |
| --- | --- | --- |
| 1수 앞 봇이 받은 피해 합(층마다 체력 5) | 0 | 13 (6~9층 2씩, 10층은 실패) |
| 2수 앞 / 3수 앞 봇이 받은 피해 합 | 0 / 0 | 0 / 0 |
| 10층을 이어서: 1수 앞 | — | 8/10층, 9층에서 체력 0 |
| 10층을 이어서: 2수 앞 / 3수 앞 | — | 완주 148턴 / 완주 137턴, 피해 0 |
| 제자리 베기만 / 도망만 / 맴돌기 | 0층 / 0층 / 1층 | 같음(1~2층에서 끝난다) |

- 버린 대안: (가) 체험 층까지 어렵게 — 처음 하는 사람이 다치며 배우게 되어 체험 구간의 목적(재미를 겪게 한다)과 어긋난다. (나) "밟기 처치 시 칼 회수" 같은 규칙 추가 — 대표 소감 없이 규칙을 더 바꿀 근거가 없다.
- 남은 의문: 1수 앞 봇이 다치는 이유는 2턴 뒤 폭발을 보지 못해서다. 사람이 폭탄 숫자를 읽으면 다치지 않을 수 있다(그것이 의도). 사람에게 본편이 어려운지 쉬운지는 봇으로 알 수 없다.

### 3. 되감기 (추가 — GAME_DESIGN 6.6 그대로)
- 무엇을: 층마다 1회, 직전 턴의 확정을 취소하고 그 턴 시작 상태로 돌린다. 층이 바뀌면 다시 1회.
- 왜: 본편에서 읽기 실수 한 번은 구제한다(오터치 포함). 결정론이라 되감은 뒤 같은 행동을 하면 같은 결과다.
- 시뮬레이션: 하지 않았다 — 상태 복원이라 규칙의 균형에 영향이 없고, 봇은 실수하지 않아 쓰지 않는다. 칼 상태·메아리·폭탄 시계·증원 예고가 모두 한 턴 전으로 돌아가야 한다는 것만 기획실이 검사로 확인하면 된다.

## 기획실에 넘기는 메모

- **기존 콘텐츠의 정답은 달라지지 않는다.** 규칙을 바꾸지 않았고 1~5층도 그대로다. 다만 기본 층 수가 5 → 10이 되므로 층 수를 보는 검사와 "5층 클리어 → 승리"를 보는 검사는 바뀐다.
- **꼭 검사해야 할 새 규칙**
  1. 폭탄병의 의도: 쿨다운 0이고 거리 3 이하면 던지기(대상 = 그때의 플레이어 칸), 아니면 졸개처럼. 던진 뒤 쿨다운 3이고, 쿨다운은 던지지 않은 턴마다 1씩 준다(sim.py `step`의 쿨다운 줄).
  2. 폭탄 시계: 던진 턴에 남은 턴 2로 놓이고 **그 턴의 4단계에서 바로 1이 된다**(sim.py: 던지기 → 같은 턴 폭탄 단계에서 −1). 즉 던진 다음 턴이 끝날 때 터진다. 범위는 그 칸 + 상하좌우, 벽·보드 밖은 그냥 빠진다. 메아리는 폭발을 막지 않는다(sim.py에 막는 코드 없음).
  3. 폭발의 오사: 범위 안의 적 피해 1(방패 무효 없음), `kills.friendly`.
  4. 되감기: 층당 1회, 턴 0에서는 불가, 쓴 뒤에는 불가, 새 층에서 다시 가능. 되감으면 플레이어·체력·적·폭탄·증원 예고·이력(발자국, 칼)·처치 수가 전부 한 턴 전과 같다.
  5. 본편 기준이 지켜지는지: 10개 층 정답 재생(3수 앞, 피해 0).
- **함정**
  - sim.py의 폭탄병 쿨다운 감소는 "이번 턴 의도가 던지기가 아닌 폭탄병"에게만 적용된다.
  - 폭탄병은 붙어 있어도 치지 않는다(sim.py `compute_intents`: 치기는 졸개·방패병만). 쿨다운 중이고 거리 1이면 의도가 없다.
  - 폭발은 플레이어에게 한 번만 피해를 준다(범위 칸을 돌며 플레이어 칸일 때 1번).
  - 메아리는 폭발을 막지 않는다. GAME_DESIGN 6.3의 예전 문장("폭발을 받으면 막는다")이 sim.py와 달라 이번에 문서를 sim.py에 맞춰 고쳤다.
- 층 6~10의 좌표는 `sim.py` `CAMPAIGN`. 기획실이 정답 재생으로 다시 확인하고, 문제가 있으면 같은 기준으로 다른 후보를 골라도 된다.
- 체험 구간 끝 표시는 규칙이 아니라 화면이다(5층 클리어 뒤 6층 시작 전).
