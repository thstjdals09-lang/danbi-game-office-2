# 메아리 발자국 — 화면 (2차 빌드)

2차에서 바뀌거나 더해진 항목은 끝에 **(2차)** 를 붙였다. 표시가 없는 항목은 1차 그대로다.

기준 크기 세로 540×960. 위치는 대략이며, 픽셀 배치는 빌드실이 정한다. 단 보드는 화면 위쪽 60% 안, 버튼은 엄지가 닿는 아래쪽에 둔다.
모든 정보는 색만이 아니라 **모양·숫자·무늬**로도 구분되어야 한다(디자인 12절, 14절).

## title — 타이틀

```
┌──────────────────────────┐
│                          │
│        메아리 발자국       │
│   지금의 한 걸음이         │
│   3턴 뒤의 칼이 된다       │
│                          │
│      ○ ‥ ③ ② ①          │  ← 플레이어 원과 발자국 그림
│                          │
│     화면을 눌러 시작       │
│                          │
└──────────────────────────┘
```

요소
- 제목, 한 줄 설명
- 플레이어 원 + 발자국 ③②① 그림(게임 안과 같은 모양 — 발자국 숫자의 뜻을 미리 보여 준다)
- "화면을 눌러 시작"

동작
- 화면 어디든 탭 → play(1층)

## play — 플레이

```
┌──────────────────────────┐
│ 1/5층   턴 4/60   ♥♥♥♥♡  │  ← 위 띠
├──────────────────────────┤
│ ┌─┬─┬─┬─┬─┬─┬─┐          │
│ │ │ │ │▲│ │ │ │          │  ▲ 궁수(꼭짓점이 조준 방향)
│ ├─┼─┼─┼╎┼─┼─┼─┤          │  ╎ 조준 사선(빗금)
│ │ │█│ │╎│ │█│ │          │  █ 벽
│ │ │ │ │╎│ │ │ │          │
│ │■→│ │ │◌│ │ │ │          │  ■ 졸개, → 이동 의도   ◌ 메아리(점선 원)
│ │ │ │②│①│ │ │ │          │  ①②③ 발자국(①이 다음 턴)
│ │ │ │③│●│ │ │ │          │  ● 플레이어
│ └─┴─┴─┴─┴─┴─┴─┘          │  ← 보드 7×7 (화면 위쪽)
├──────────────────────────┤
│ 처치 밟기 0·베기 1·오사 0·으깨기 0 │  ← 아래 띠
│                          │
│   [ 베기 ]      [ 대기 ]   │  ← 엄지 영역 버튼. 칼이 없으면 [ 칼 ② ]
│   아무 곳이나 밀어서 이동    │
└──────────────────────────┘
```

요소
- 위 띠: 층(현재/전체), 턴(현재/60), 체력 하트 5칸(남은 것은 꽉 찬 하트, 잃은 것은 빈 하트)
- 보드 7×7: 바닥은 얇은 격자선, 벽은 칸을 꽉 채운 짙은 사각형
- 플레이어: 흰 원
- 메아리: 플레이어와 같은 크기의 반투명 원 + 점선 외곽. 메아리가 아직 없을 때(첫 3턴)는 그리지 않는다
- 발자국: 작은 원 안의 숫자 ①②③. ①이 다음 턴에 메아리가 재생할 칸. 베기였던 발자국은 벨 방향으로 짧은 선을 덧그린다. 대기였던 발자국은 숫자만
- **칼이 실린 발자국**: 베기였던 발자국은 원 테두리를 굵게(다른 발자국의 2배) 그리고 칼 선도 굵게 그린다. "내 칼이 지금 여기에 있다"가 한눈에 보여야 한다 (2차)
- 플레이어의 칼: 칼이 손에 있으면 흰 원 오른쪽 위에 짧은 칼 선을 그리고, 칼이 없으면(`sword_wait > 0`) 그리지 않는다 (2차)
- 졸개: 정사각형. 궁수: 삼각형
- 방패병: 정사각형 + **바라보는 쪽 변에 두꺼운 밝은 막대**(방패). 막대가 붙은 쪽에서 오는 일격은 통하지 않는다는 뜻이다. 의도가 바뀌어 바라보는 방향이 달라지면 막대도 그 변으로 옮겨 간다 (2차)
- 적 체력: 체력이 2 이상으로 시작하는 적(방패병)은 도형 안에 **남은 체력만큼 작은 점**(●● → ●). 체력 1짜리 적에는 그리지 않는다 (2차)
- 적 의도(턴 시작에 이미 공개):
  - 이동: 적에서 도착 칸으로 짧은 화살표
  - 치기: 대상 칸에 주먹 표시 + 굵은 테두리
  - 조준: 궁수에서 벽·적·메아리에 막힐 때까지 사선 전체에 빗금 무늬 + 끝에 화살촉
- 위험 칸: 지금 공개된 의도대로면 다음 적 행동에서 피해가 나는 칸에 "!" (플레이어가 그 칸에 있거나 그 칸으로 가려 할 때 판단하도록)
- 증원 예고: 등장할 칸에 점선 원 + 남은 턴 숫자
- 아래 띠: 이번 런의 처치 수(밟기 · 베기 · 오사 · 으깨기) (2차)
- 버튼: **베기**(토글), **대기**. 그 아래 한 줄 안내 "아무 곳이나 밀어서 이동"
- **칼이 없을 때의 베기 버튼**: 글자가 "칼 ③"/"칼 ②"/"칼 ①"(숫자 = `sword_wait`, 돌아올 때까지 남은 턴)로 바뀌고 버튼이 어둡게(테두리 점선) 그려진다. 안내 줄은 "칼은 메아리가 휘두른 뒤 돌아옵니다" (2차)

동작
- **밀기(스와이프)**: 화면 어디서든 24px 이상 밀었다 떼면, 가장 크게 움직인 축의 방향으로
  - 베기 토글이 꺼져 있으면 → 그 방향으로 이동
  - 베기 토글이 켜져 있으면 → 그 방향으로 베기, 그리고 토글이 꺼진다
- **베기 버튼**: 탭하면 토글. 켜져 있는 동안 버튼이 눌린 모양(굵은 테두리 + "베기 ▶ 방향을 미세요")
- **칼이 없을 때 베기 버튼을 탭**: 토글이 켜지지 않는다. 버튼이 좌우로 짧게 흔들리고, 칼이 실린 발자국이 0.3초 동안 밝게 깜빡인다(칼이 어디 있는지 가리킨다). 턴은 쓰지 않는다. 이어서 밀면 이동이다 (2차)
- **대기 버튼**: 탭하면 대기로 한 턴
- **미리보기**: 누른 채 24px 이상 민 동안
  - 이동이면 도착 칸에 윤곽, 베기면 대상 칸에 칼 선
  - 이 행동이 3턴 뒤 메아리의 타격이 될 칸에 점선 X와 "③" (이동이면 도착 칸, 베기면 대상 칸)
  - 손가락을 시작점 24px 안으로 되돌려 떼면 취소(아무 일도 없음)
- **불가능한 행동**(벽·보드 밖·적이 있는 칸으로 이동, 벽·보드 밖으로 베기): 플레이어가 좌우로 짧게 흔들리고 턴은 쓰지 않는다
- 연출이 도는 동안 새로 누르면 연출을 즉시 끝까지 넘기고, 그 입력은 정상 입력으로 그대로 처리한다(입력을 버리지 않는다)

피드백 (디자인 12절 중 이번 빌드)
| 사건 | 표시 |
| --- | --- |
| 이동 확정 | 플레이어가 0.12초 미끄러짐, 발자국 ③ 생김 |
| 베기 확정 | 칼 궤적이 잠깐 그어졌다 사라짐, 발자국에 칼 선 |
| 메아리 밟기·베기 명중 | 메아리가 순간 불투명, 0.08초 정지, 적이 조각으로 흩어짐, 그 칸에 "밟기!" 또는 "베기!" |
| 오사 | 화살이 적에게 꽂히고 조각으로 흩어짐, "오사!" |
| 메아리가 화살을 막음 | 메아리 앞에 파문 + "막음" |
| 일격에 살아남은 적이 밀림 (2차) | 적이 일격 방향으로 한 칸 미끄러지고 체력 점이 하나 줄어듦. 그 칸에 "밟기!" 또는 "베기!" (처치가 아니어도 명중 글자는 뜬다) |
| 으깨기 (2차) | 적이 막힌 쪽으로 반 칸 갔다가 납작해지며 조각으로 흩어짐, "으깨기!" |
| 방패가 일격을 튕김 (2차) | 방패 막대가 번쩍이고 "튕김" 글자. 적은 움직이지 않는다 |
| 칼이 돌아옴 (2차) | 메아리가 벤 턴이 끝나면 베기 버튼이 다시 "베기"로 채워지고 플레이어 원에 칼 선이 다시 그려짐 |
| 피격 | 화면 가장자리 붉은 테두리 + 플레이어 원의 외곽이 깨진 선으로 0.3초 |
| 체력 1 | 플레이어 외곽이 계속 점선 |
| 층 클리어 | 발자국이 모두 빛나며 사라지고 "2층" 글자가 잠깐 뜬 뒤 다음 층 |

- 한 턴의 연출은 모두 합쳐 0.9초를 넘지 않는다.

## result — 결과

```
┌──────────────────────────┐
│                          │
│        런 승리!           │  (패배면 "쓰러졌다" 또는 "메아리가 무너졌다")
│                          │
│   도달  5 / 5층           │
│   처치  밟기 8 · 베기 9   │
│        오사 0 · 으깨기 3  │
│   남은 체력 ♥♥♥♥♥        │
│                          │
│     화면을 눌러 다시       │
│                          │
└──────────────────────────┘
```

요소
- 결과 제목: 승리 "런 승리!" / 체력 0 패배 "쓰러졌다" / 60턴 패배 "메아리가 무너졌다 (60턴)"
- 도달 층, 처치 출처별 수(밟기 · 베기 · 오사 · 으깨기, 두 줄로 나눠도 된다) (2차), 남은 체력
- 패배면 한 줄 원인: "n턴, 졸개의 치기" 또는 "n턴, 방패병의 치기" (2차) 또는 "n턴, 궁수의 화살" 또는 "60턴 안에 층을 비우지 못함" (디자인 15절 "실패의 공정함")
- "화면을 눌러 다시"

동작
- 화면 어디든 탭 → play(1층부터 새 런)
