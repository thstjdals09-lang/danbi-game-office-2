# 규칙 시뮬레이션 결과 — 메아리 발자국

실행: `python3 sim.py` (표준 라이브러리, 시드 고정, 약 3분, exit 0). 마지막 출력 원본: `last_output.txt`.
`sim.py`는 GAME_DESIGN.md 6절 규칙(턴 순서, 메아리 밟기/베기, 밀치기·으깨기, 적 4종, 폭탄, 증원, 60턴 제한)과
8절 층 생성 규칙을 그대로 구현한다. 유물은 지연(d) 변경만 구현했다.

## 전략(봇)
| 이름 | 하는 일 |
| --- | --- |
| 무작위 | 가능한 행동 중 무작위 |
| 도망만 | 공개된 위험 칸을 피하고 적에게서 멀어짐. 베기 안 함(메아리를 모르는 플레이어) |
| 2×2 맴돌기 | 오른쪽·아래·왼쪽·위 반복(한 가지 패턴) |
| k수 앞 | k턴 깊이 전수 탐색 + 평가(체력, 처치, 가장 가까운 적까지 경로, 이미 확정된 메아리 d턴 재생 시 처치 수) |

## 1차 실행에서 발견한 문제와 설계 변경
| 관찰(숫자) | 원인 | 설계 변경 |
| --- | --- | --- |
| 2수 앞 봇이 8런 중 7런이 2~3층에서 피해 0으로 60턴 교착 | 궁수가 고정 포대 → 메아리 밟기로 못 잡고, 사선을 피해 옆으로 가는 길이 없으면 아무 일도 안 일어남 | 궁수: 사선이 없으면 플레이어 쪽으로 이동(6.5) |
| 궁수 옆에서 베면 반드시 맞음 | 궁수가 붙은 대상도 쏨 | 궁수 최소 사거리 2 |
| 시드 4의 2층이 풀 수 없음 | 벽이 (0,0) 주머니를 막아 졸개가 갇힘 | 층 생성 연결성 검사 |
| 궁수 이동 후 2수 앞 봇 20/20 클리어, 피해 0 | 너무 쉬움 | 4~8층 적·증원 수 상향(8절 표) |

## 그래서 바꾼 설계 / 내린 결론
1. **핵심 메커닉 필요성 통과**: 메아리를 쓰지 않는 도망 전략은 평균 0.2층. 플레이어는 직접 피해를 줄 수 없으니 당연하지만, "버티기만 해도 된다"가 막혀 있다는 것을 60턴 제한·증원으로 확인.
2. **지배 전략 없음**: 맴돌기·무작위·탐욕 모두 실패. 성과가 계획 깊이(1→2→3수)에 따라 4.8 → 7.0 → 8.0층으로 단조 증가.
3. **메아리 지연 3 확정**: 계획 이득이 가장 크다. d=2는 교착(메아리가 바로 뒤에서 적의 길을 막는 것으로 보임, 로그 관찰 기반 추정)이라 "짧은 메아리" 유물을 삭제했다. d=4는 "긴 메아리" 유물로 유지(이득은 남고 체력 탈락이 늘어 위험·보상 성격).
4. **베기의 위치**: 베기 금지 봇도 깬다. 베기는 필수가 아니라 가장 효율적인 도구(처치 48%). 방패병·고정형 적을 추가하면 필수가 되지만, 지금은 "두 가지 공격 방식 중 고르는 판단"으로 둔다.
5. **한계**: 봇은 완벽히 읽기 때문에 피해를 거의 받지 않는다. 피해 기준 난이도와 정보 과부하(6층 이후)는 사람 플레이테스트로만 확인 가능 → GAME_DESIGN 16절.
