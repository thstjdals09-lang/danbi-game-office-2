# 같은 하루 — 화면 (첫 빌드)

기준 크기 세로 540×960. 위치는 대략이며 픽셀 배치는 빌드실이 정한다. 지도는 화면 위쪽, 선택지와 단추는 엄지가 닿는 아래쪽에 둔다.
정보는 색만이 아니라 **모양·글자**로도 구분한다(디자인 12·14절). 이 게임에는 입력을 막는 연출이 없다 — 어떤 연출 중에도 입력은 즉시 처리된다.

## title — 타이틀

```
┌──────────────────────────┐
│                          │
│         같은 하루          │
│   마을은 3분마다 아침으로    │
│   돌아간다. 나만 기억한다.   │
│                          │
│          ( ↺ )           │  ← 바늘이 거꾸로 도는 시계
│                          │
│     화면을 눌러 첫 아침      │
└──────────────────────────┘
```

요소
- 제목, 두 줄 설명, 바늘이 거꾸로 도는 시계 그림, "화면을 눌러 첫 아침"

동작
- 화면 어디든 탭 → day(1바퀴째, 06:00, 여관)

## day — 하루

```
┌──────────────────────────┐
│ 06:00 ──▼────┼──────── 18:00 │  ← 시계 띠: 바늘, 정오 눈금, 아는 장면 표식
│ 2번째 하루   07:28 (11틱)  [도장]│
├──────────────────────────┤
│        종탑△      우체국□   │
│           \       /      │
│  나루터◠ ──── 광장○ ──── 여관⌂ │  ← 마을 약도(장소 7, 길과 틱 수)
│     \        / \     |   │
│      대장간▭      빵집▣     │     ● 나   (보) 주민   ⚑1 ⚑2 예약 깃발
├──────────────────────────┤
│ 빵집 — 보리                 │  ← 장면 창
│ "장작이 다 떨어졌네, 무쇠네서…" ✎새로 알았다 │
│ [ 장작을 준다 ] [ 쪽지를 주워 준다 ·수첩 덕분 ] │
│ 손: 장작                    │
├──────────────────────────┤
│ [수첩] [흘려보내기] [예약 지우기] [잠들기] │
└──────────────────────────┘
```

요소 — 위 띠
- **시계 띠**: 왼쪽 06:00, 가운데 정오 눈금, 오른쪽 18:00. 지금 시각의 바늘. 수첩에 있는 장면마다 그 `t0` 자리에 작은 표식(주민 머리글자)
- 몇 번째 하루, 지금 시각(06:00 + 8분 × 틱)과 틱 수, 사건 도장(찍혔으면 "식은 화덕 ✔", 아니면 빈 테두리)

요소 — 지도
- 장소 7곳: 서로 다른 모양의 큰 도형 + 이름(여관 = 지붕 달린 사각형, 빵집 = 굴뚝 있는 사각형, 광장 = 원, 우체국 = 봉투 무늬 사각형, 대장간 = 모루 모양, 종탑 = 높은 삼각형, 나루터 = 물결선 위의 반원). 탭 대상 지름 72px 이상
- 길: 굵은 선. 가운데에 걸리는 틱 수 작은 글자
- 나: 채워진 원. 걷는 중에는 길 위를 따라 움직인다
- 주민: 머리글자(보·다·무·소)가 든 원
  - 지금 내가 서 있는 장소에 있는 주민: 진한 원
  - 그 밖에는: 본 적 있는 (주민, 지금 틱)의 장소에 **옅은 원**(예상 위치). 본 적 없는 시각이면 안 보인다
- 걷는 중: 목적지에 깃발, 지나갈 길에 점선. 예약된 장소에는 번호 깃발(1·2·3)
- 먼 신호: 연기 장면이 지금 보이는 조건이면(내가 광장·여관·우체국에 서 있고 24~29틱, 빵이 탔을 때) 빵집 굴뚝 위에 검은 연기 표시

요소 — 장면 창
- 첫 줄: 서 있는 장소 이름과 여기 있는 주민 이름. 걷는 중이면 "○○으로 가는 중 — △틱 남음"
- 장면 글: 지금 내 장소에서 보이는 장면의 `text`. 새로 적힌 것이면 연필 표시와 "새로 알았다" 띠, 이미 아는 것이면 체크 표시
- 아무 장면도 없으면 옅은 글 "지금은 아무 일도 없다"(첫 아침 0틱에는 "지도의 장소를 눌러 가 보세요")
- **선택지 단추**: `choices`의 행동마다 `label`. 수첩 조건(`know`)이 있는 행동에는 "수첩 덕분" 딱지. 바쁠 때(걷는 중·행동 중)는 같은 자리에 예약할 수 있는 선택지가 "예약" 딱지와 함께 뜬다
- **늦은 선택지**: `late_choices`의 행동은 회색 단추 + "늦었다 — 14틱(07:52)까지". 누를 수 없다
- 하고 있는 행동: "장작을 든다…" 진행 표시
- 버려진 예약(`last_missed`): "놓쳤다: 장작을 준다" 한 줄(다음 입력까지)
- 소지품: "손: 장작" (없으면 "손: 빈손")

요소 — 맨 아래 단추
- **수첩**, **흘려보내기**(누르고 있는 동안), **예약 지우기**(예약이 있을 때만 밝게), **잠들기**(길게)

동작
- **장소 탭**: 한가하면 그곳으로 걷기 시작. 바쁘면 예약(3개까지). 제자리·오늘 안에 못 닿는 곳·예약이 가득 찼을 때는 그 장소 도형이 짧게 흔들리고 한 줄 이유("오늘 안에 못 닿는다" / "예약은 3개까지")
- **선택지 탭**: 한가하면 바로 시작(1틱 동안 진행 표시). 바쁘면 예약 — 단추에 예약 번호
- **수첩**: notebook으로(시간이 멈춘다)
- **흘려보내기**: 누르고 있는 동안 4배속(1틱 0.5초). 떼면 원래대로. 누르는 동안 시계 띠에 "▶▶"
- **예약 지우기**: 예약 줄을 비운다(지금 걷고 있는 걸음과 하고 있는 행동은 그대로)
- **잠들기**: 0.6초 길게 누르면 테두리가 차오르고, 다 차면 하루를 끝낸다 → result. 짧게 누르면 "길게 눌러 잠들기"

피드백 (디자인 12절 중 이번 빌드. 소리·진동 없음)
| 사건 | 표시 |
| --- | --- |
| 장소 탭 | 목적지에 깃발, 길에 점선 |
| 예약 | 깃발·단추에 번호 |
| 도착 | 장면 창이 아래에서 0.15초 올라옴 |
| 새 사실 | 수첩 단추가 튀고 "새로 알았다" 띠, 장면 글 옆 연필 표시, 시계 띠에 표식이 생김 |
| 이미 아는 장면 | 띠 없음, 체크 표시 |
| 수첩 덕분에 생긴 선택지 | 단추가 한 번 반짝이고 "수첩 덕분" 딱지 |
| 끼어들기 끝 | 주민 원 위에 반응 기호(!)와 한 줄("보리가 빵집을 비우지 않는다") |
| 시간 창을 놓침 | 회색 단추 + "늦었다 — ○틱까지" |
| 예약이 버려짐 | "놓쳤다: …" 한 줄, 장면 창이 짧게 흔들림 |
| 먼 신호 | 지도의 빵집 위에 연기 |
| 틱이 넘어감 | 시계 바늘이 한 칸 움직임 |
| 하루 끝 | 화면이 0.4초 어두워지며 바늘이 거꾸로 돈다 → result |

## notebook — 수첩

```
┌──────────────────────────┐
│ 수첩 — 시간표         [닫기] │
│      06   08   10   12 … │  ← 시각 눈금(가로로 민다)
│ 보리  ·  ▣쪽지가 날아감 ▣반죽 ▣장작이… │
│ 다래  ·  ▣쪽지를 두고 감        │
│ 무쇠  ·                     │
│ 소리  ·                     │
│                          │
│ 07:12 보리 — 문바람에 쪽지가   │  ← 고른 칸의 글
│ 계산대 밑으로 날아간다 (빵집)   │
└──────────────────────────┘
```

요소
- 제목 "수첩 — 시간표", 닫기 단추
- 주민 4명의 가로 줄(보리·다래·무쇠·소리). 수첩에 있는 장면이 `who`의 줄, `t0`의 시각 칸에 놓인다(장면의 `t0`~`t1` 길이만큼의 띠)
- 이번 바퀴에 새로 적힌 칸에는 연필 표시
- 지금 시각의 세로 선
- 아래: 고른 칸의 시각, 주민, 장면 글, 장소 이름. 아무것도 적힌 게 없으면 "아직 본 것이 없다. 어딘가에 서서 지켜보자."

동작
- 칸 탭 → 아래에 그 장면의 글
- 가로로 밀기 → 시각 눈금 이동
- 닫기 → day(시간이 다시 흐른다). 수첩이 열려 있는 동안 시간은 멈춘다

## result — 오늘의 결과

```
┌──────────────────────────┐
│        2번째 하루 끝        │
│                          │
│   [ 식은 화덕 ✔ 점심이 차려졌다 ] │  (안 풀렸으면 빈 도장 + "여관의 점심은 없었다")
│                          │
│   오늘 새로 안 것 2          │
│   ✎ 빵집 굴뚝에서 검은 연기가… │
│   ✎ 다래: 빵이 안 왔네…      │
│                          │
│   늦은 매듭                 │
│   장작을 준다 — 14틱(07:52)까지 │
│                          │
│   화면을 눌러 다음 아침       │
└──────────────────────────┘
```

요소
- 몇 번째 하루가 끝났는지
- 사건 도장: 이번 하루에 풀렸으면 도장이 찍히는 연출과 "점심이 차려졌다", 아니면 빈 도장과 "여관의 점심은 없었다"
- 오늘 새로 안 것: 개수와 장면 글 목록(0개면 "새로 안 것이 없다 — 다른 곳, 다른 시각에 서 보자")
- 늦은 매듭: 행동 이름과 마감 시각(없으면 이 줄을 숨긴다)
- "화면을 눌러 다음 아침"

동작
- 화면 어디든 탭 → day(다음 바퀴, 06:00, 여관). 표지·소지품은 사라지고 수첩은 남는다
