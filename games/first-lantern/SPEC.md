# First Lantern · 기획서 v1

> 파이프라인 시험 게임. 빌드 → CI 자동 검사 → Web export → 대시보드 플레이까지 한 바퀴 도는지 확인하려고 만들었다.

- **한 줄:** 꺼지기 전에 등불을 눌러 밝힌다
- **화면:** 세로 540×960
- **조작:** 화면 탭 한 가지
- **흐름:** 등불이 나타남 → 꺼지기 전에 탭 → 놓치면 목숨 -1 → 점점 빨라짐
- **끝:** 45초가 지나거나 3번 놓치면 끝
- **아트:** 어두운 남색 밤, 따뜻한 노란 불빛. 도형과 기본 폰트만 사용

## 화면

| id | 내용 |
| --- | --- |
| title | 제목, 시작 안내, 최고 기록 |
| play | 등불들, 점수, 남은 시간, 목숨 |
| result | 점수, 최고 기록, 다시 하기 |

## must_work

| id | 내용 | 확인 방법 (`tests/smoke.gd`) |
| --- | --- | --- |
| M1 | 타이틀 화면에서 시작한다 | 실행 직후 `state == TITLE` |
| M2 | 탭하면 플레이가 시작된다 | 타이틀에서 탭 → `state == PLAY` |
| M3 | 등불을 누르면 점수가 1 오른다 | 등불 근처 탭 → `score == 1` |
| M4 | 놓친 등불은 목숨을 1 깎는다 | 등불 수명 초과 → `lives == 2` |
| M5 | 목숨이 0이면 결과 화면으로 가고 최고 기록이 남는다 | `lives = 0` → `state == RESULT`, `best >= 1` |
| M6 | 결과 화면에서 탭하면 다시 시작한다 | 탭 → `state == PLAY`, `score == 0` |
