# 불길 속으로 — 화면 (첫 빌드)

기준 크기 세로 540×960. 위치는 대략이며 픽셀 배치는 빌드실이 정한다. 단 보드는 화면 위쪽 64% 안, 버튼은 엄지가 닿는 아래쪽에 둔다.
모든 정보는 색만이 아니라 **모양·숫자·무늬**로도 구분되어야 한다(디자인 12절, 14절). 이번 빌드는 **건물 전체가 보인다**(안개 없음).

## title — 타이틀

```
┌──────────────────────────┐
│                          │
│        불길 속으로         │
│   문을 열면 불이 깨어난다    │
│   닫으면 불이 굶는다        │
│                          │
│     ▢│◦◦◦   ▢/▲▲▲        │  ← 닫힌 문 뒤의 숨죽은 불 / 열린 문 뒤의 불
│                          │
│     화면을 눌러 출동        │
└──────────────────────────┘
```

요소
- 제목, 두 줄 설명
- 그림 한 쌍: 닫힌 문 뒤의 숨죽은 불(동그라미)과 열린 문 뒤의 불(불꽃). 게임 안과 같은 모양으로 그려 핵심 규칙을 미리 보여 준다
- "화면을 눌러 출동"

동작
- 화면 어디든 탭 → play(건물 1 「첫 출동」)

## play — 출동

```
┌──────────────────────────┐
│ ♥♥♥♥  공기 140  물 8  사람 0/2 │  ← 위 띠
│ 1/3 첫 출동        박자 ●○  │  ← 건물, 박자 표시(다음 행동에 불이 움직이면 ●●)
├──────────────────────────┤
│ ###########              │
│ #~~~#.#ooo#   o 숨죽은 불   │
│ #~~~#.+ooo#   + 닫힌 문(징후)│
│ #P~~#.#ooo#   P 사람(숨 눈금)│
│ #~~~#.#...#              │
│ #~~~+.#...#              │
│ #~~~#.#...#              │  ← 보드 11×13 (칸 44px, 화면 위쪽)
│ #~~~#.#...#              │
│ ###/#.#+###   / 열린 문     │
│ V~~~+.#___#   V 깨진 창     │
│ #~~P#.+___#              │
│ #~~~#.#___V              │
│ #####E#####   E 출구 = 나   │
├──────────────────────────┤
│ [ 물 ] [문 닫기] [업기] [기다리기] │  ← 엄지 영역 버튼 4개
│      아무 곳이나 밀어서 걷기   │
└──────────────────────────┘
```

요소 — 위 띠
- 체력 하트 4칸, 공기(숫자와 막대. 20 이하이면 깜빡임, 0 아래면 붉게), 물(숫자와 물방울), 사람(구한 수 / 전체)
- 건물 번호와 이름, **박자 표시**: 점 두 개. 지금까지 쓴 행동 수가 홀수이면(다음 행동에 불이 움직이면) 두 개 다 채워진다

요소 — 보드
- 벽: 굵고 어두운 블록. 깨진 창: 벽에 금 간 유리 무늬. 출구: 아래쪽 벽의 밝은 칸
- 바닥 재질 무늬: 나무(긴 널), 카펫(점), 종이 더미(겹친 사각형), 타일(격자), 가구(굵은 테두리 블록 — 지나갈 수 없음)
- 문: 벽 사이의 얇은 막대. 열리면 90도 돌아간다. 탄 문은 그을린 문틀만 남는다
- **문 징후**(닫힌 문에 항상):
  - `none`: 표시 없음
  - `burning`(문 너머에서 불타는 중): 문이 붉게 달아오름
  - `smolder`(숨죽음, 가스 4 이하): 문틈에서 점 3개가 **바깥으로** 새어 나옴
  - `backdraft`(가스 5 이상): 점이 **안쪽으로** 빨려 들어감 + 문이 떨림 + 화염이 지나갈 칸(문 칸과 문 밖 3칸)에 빗금
- 불: 주황 불꽃 삼각형(일렁임). 숨죽은 불: 재색 동그라미. 재: 어두운 점. 젖음(열이 음수): 파란 물방울 무늬. 잔해: 엇갈린 막대
- **열 눈금**: 불이 없는 칸의 모서리에 금(틈)을 열의 수만큼. 열이 발화 열보다 1 적으면 칸이 떨린다
- **예보 "!"**: 다음 불 박자에 새로 불이 붙을 칸에 "!"
- 방 테두리: 밀폐된 방은 테두리가 굵다. 방 구석에 공기 눈금(공기 / 가득). 숨죽은 방은 어둡게 + 가스 숫자. 버팀이 5 이하인 방은 테두리에 남은 버팀 숫자와 먼지. 무너진 방은 전체가 잔해 무늬
- 연기: 연기 속인 방 묶음에 반투명 회색 줄무늬
- 구조 대상: 흰 원 + 숨 눈금 12칸(3칸씩 4덩이). 숨 3 이하이면 깜빡임. 사망하면 회색 ×
- 소방관: 노란 원 + 헬멧 띠. 업으면 원 위에 작은 흰 원이 겹친다

요소 — 아래
- 버튼 4개: **물**(남은 물 숫자), **문 닫기**, **업기 / 내려놓기**(지금 가능한 쪽의 이름), **기다리기**
- 출구 칸에 서 있을 때만 **철수** 버튼이 나타난다(버튼 줄 위나 옆)
- 쓸 수 없는 버튼은 어둡게: 물 0 또는 업고 있음 → 물 / 닫을 문 없음 → 문 닫기 / 업을 사람도 내려놓을 자리도 없음 → 업기
- 한 줄 안내: 평소 "아무 곳이나 밀어서 걷기", 방향 대기 중 "물을 뿌릴 방향으로 미세요" / "닫을 문 쪽으로 미세요"

동작
- **밀기(스와이프)**: 화면 어디서든 24px 이상 밀었다 떼면 가장 크게 움직인 축의 방향으로
  - 방향 대기가 없으면 → 그 방향으로 걷기(닫힌 문 쪽이면 문 열기)
  - 방향 대기가 "물"이면 → 그 방향으로 물, "문 닫기"면 → 그 방향의 문 닫기. 대기는 풀린다
- **물 버튼**: 방향 대기 "물"로. 다시 누르면 취소. 물이 0이거나 업고 있으면 아무 일도 없다(버튼이 짧게 흔들림)
- **문 닫기 버튼**: 닫을 수 있는 문이 하나면 즉시 닫는다. 둘 이상이면 방향 대기 "문 닫기". 없으면 아무 일도 없다(흔들림)
- **업기 / 내려놓기 버튼**: 가능한 쪽을 한다
- **기다리기 버튼**: 한 행동을 보낸다
- **철수 버튼**: 출동을 끝내고 result로
- **방향 대기 중 미리보기**: 물이 닿을 칸(최대 3칸)에 물줄기 윤곽 / 닫을 수 있는 문에 굵은 테두리와, 닫으면 밀폐되는 방의 윤곽
- **불가능한 행동**(벽으로 걷기, 닫을 수 없는 문, 물이 막힌 방향 등): 소방관이 좌우로 짧게 흔들리고 행동 수를 쓰지 않는다
- 연출이 도는 동안 새로 누르면 연출을 즉시 끝까지 넘기고, 그 입력은 정상 입력으로 그대로 처리한다(입력을 버리지 않는다)

피드백 (디자인 12절 중 이번 빌드. 소리·진동 없음)
| 사건 | 표시 |
| --- | --- |
| 걷기 | 0.12초 미끄러짐. 업고 걷기는 조금 느리게(두 박자에 걸쳐) |
| 불 박자 | 박자 표시가 뛰고 불 칸이 한 번 크게 일렁임 |
| 열 +1 | 그 칸 모서리에 금 하나가 생김 |
| 발화 | 칸이 0.15초 번쩍한 뒤 불꽃 |
| 물 | 물줄기가 지나가고 맞은 칸에 김과 물방울 무늬 |
| 문 열기 / 닫기 | 문짝이 돌아감 / 닫히며 방 테두리가 굵어짐 |
| 방 숨죽음 | 불꽃이 낮아지며 재색 동그라미로, 방이 어두워짐 |
| 흡입(역류 직전 박자) | 문틈의 점들이 안쪽으로 빨려 듦, 지나갈 칸의 빗금이 진해짐 |
| 역류 폭발 | 0.2초 멈춘 뒤 화염 줄, 화면 흔들림, "역류!" |
| 사람 숨 −1 | 눈금 한 칸이 꺼짐. 3 이하이면 깜빡임과 기침 표시 |
| 업기 / 구조 완료 | 소방관 위에 작은 원이 겹침 / 출구에서 사람이 걸어 나감 + "구조!" |
| 붕괴 예고 / 붕괴 | 방 테두리의 숫자와 먼지 / 방 전체가 잔해로 + 화면 흔들림 |
| 피해 | 소방관이 0.2초 흰색, 하트 하나가 깨짐, 화면 가장자리 붉은 테두리 |
| 사람 사망 | 흰 원이 회색 ×로 |

- 한 행동의 연출은 모두 합쳐 0.6초를 넘지 않는다(업고 걷기처럼 불 박자가 끼는 행동 포함).

## result — 결과

```
┌──────────────────────────┐
│                          │
│        ★ ★ ★             │
│      전원 구조!            │  (순직이면 "순직", 상한이면 "시간 초과")
│                          │
│   구한 사람  2 / 2         │
│   쓴 행동  62   쓴 물  0    │
│   남은 체력 ♥♥♥♥          │
│                          │
│   화면을 눌러 다음 건물      │  (마지막 건물이면 "화면을 눌러 처음으로")
└──────────────────────────┘
```

요소
- 별 0~3개와 한 줄 제목: ★★★ "전원 구조!" / ★★ "한 명을 남겼다" / ★ "일부 구조" / ★ 0 철수 "아무도 구하지 못했다" / 순직 "순직" / 상한 "시간 초과"
- 구한 사람 / 전체, 쓴 행동 수, 쓴 물, 남은 체력
- 순직이면 한 줄 원인: "불 위에 서 있었다" / "역류에 맞았다" / "방이 무너졌다" / "공기가 떨어졌다" (디자인 15절 "실패의 공정함")
- "화면을 눌러 다음 건물" 또는 마지막 건물이면 "화면을 눌러 처음으로"

동작
- 화면 어디든 탭 → play(다음 건물) 또는 title(마지막 건물 뒤)
