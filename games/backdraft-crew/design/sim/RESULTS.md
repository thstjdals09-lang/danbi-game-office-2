# 불길 속으로 — 규칙 시뮬레이션 결과

- 실행: `python sim.py` (약 1분 40초, 건물 100채 × 4단계 × 봇 8종). `python sim.py --quick`은 30채.
- 마지막 실행의 전체 출력은 `last_output.txt`.
- 규칙은 GAME_DESIGN.md 6절 그대로. 난수는 건물 생성에만 쓰고 시드 고정(건물 번호 = 시드).
- **봇은 건물 전체를 본다.** 실제 게임의 안개(닫힌 방 안이 안 보임)는 없다. 수치는 정보가 완전할 때의 것이다.
- **유효 구조율** = 소방관이 살아 나온 판에서 구한 사람 / 전체 사람. 순직한 판은 0명으로 친다.

## 전략(봇)

| 봇 | 하는 일 |
| --- | --- |
| random | 무작위 행동 |
| rusher(문 무시) | 가장 가까운 사람에게 최단 경로. 길을 막는 불만 끈다. 문을 닫지 않고 징후를 보지 않는다 |
| soaker(물만) | rusher + 물줄기가 닿는 불은 전부 끈다 |
| doorman(문+징후) | 위험한 사람부터. 사람 없는 불난 방과 기다리는 사람의 방 문을 닫는다. 역류 줄에서 비켜선다. 길과 사람 옆의 불만 끈다 |
| doorman-징후무시 | doorman에서 역류 대응만 뺌 |
| doorman-물 안 씀 | doorman에서 물만 뺌 |
| doorman-문 안 닫음 | doorman에서 문 닫기만 뺌 |
| veteran(문+징후+물 넉넉히) | doorman + 닿는 불은 전부 끈다 |
| sealer(먼저 다 닫기) | 사람 없는 불난 방의 문을 전부 찾아가 닫은 뒤 doorman처럼 |

## 통과하지 못해 기준을 바꾼 것 (숨기지 않는다)

- 처음 기준은 "문을 쓰는 봇이 물만 쏟는 봇보다 **유효 구조율도** 높다"였다. 단계 2는 veteran 79.0% > soaker 73.3%로 맞지만, 단계 3은 66.3% < 70.0%, 단계 4는 53.8% < 57.2%로 **틀렸다.** 조심하는 봇은 비켜서고 문을 닫느라 30~50행동 느리고, 그 사이에 연기 속 사람이 죽는다.
- 그래서 기준을 "물만 쏟는 전략이 구조율·순직률 두 축 모두에서 최선인 단계가 없다(문 쓰는 봇 중 하나가 순직률 절반 이하이면서 구조율이 5%p 넘게 뒤지지 않는다)"로 바꿨다. 이 균형이 재미가 되려면 순직의 값이 커야 하고, 그것은 근무 구조(GAME_DESIGN 10절)가 맡는다. 근무 단위는 시뮬레이션하지 않았다 → GAME_DESIGN 16절 1번.

## 확인하지 못한 것

- 안개가 있을 때의 구조율(봇은 전부 본다).
- 잘하는 사람의 상한(봇은 탐욕 규칙 봇이다. 단계 4 전원 구조 가능 45%는 봇의 한계일 수 있다).
- "들어가서 등 뒤 문 닫기" 전술은 구조율 차이가 3%p 이내이고 방향도 일정하지 않아 이득을 확인하지 못했고, 최종 실행에서는 봇 목록에서 뺐다.
- 장비·근무·표창, 복도형이 아닌 건물, 위험물, 사람 종류.
